# Healthcare Cost Estimator

An AI-powered healthcare insurance cost prediction system built using Machine Learning.

## Features

- Predict annual healthcare insurance costs
- Interactive Streamlit dashboard
- Gradient Boosting Regressor model
- Explainable AI insights
- Professional healthcare analytics interface

## Model Performance

- Algorithm: Gradient Boosting Regressor
- R² Score: 90.26%

## Major Cost Drivers

- Smoking Status
- BMI
- Age

## Deployment

Built with:
- Python
- Streamlit
- Scikit-Learn
- Pandas
- Joblib
